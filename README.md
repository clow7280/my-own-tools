# MyOwnTools

MyOwnTools 是一个个人 macOS 菜单栏工具，用来查看系统状态和 AI 订阅用量，也可以快速整理窗口。
需要 macOS 15 及以上，当前版本为 `0.3.1`。

## 功能

- 菜单栏从左到右显示：上传下载速度、CPU/GPU/RAM 占用竖柱、ChatGPT、Claude 与 OpenCode
  用量双层环。
  竖柱边框颜色表示温度分级，CPU/GPU 取自身温度，RAM 柱取硬盘温度，90℃ 以上闪烁警示。
  ChatGPT 与 Claude 外环为 5 小时窗口、内环为 7 天窗口；OpenCode 外环为滚动窗口、内环为每周窗口。
  同一提供方的所有周期使用统一品牌强调色，5 小时限额暂时取消时外环显示为虚点。
  某家用量拉取失败时环右上角覆盖黄色叹号，失败持续超过数据过期阈值后转红色，
  期间环体继续显示最近一次成功的数据。
- 点击菜单栏状态区打开弹窗，分三个选项卡。
  点击用量环区域直接进入 AI 选项卡，点击网速与竖柱区域进入系统选项卡，设置选项卡只能手动切换。
  - 系统：占用率含 E/P 核占用与平均负载，温度含磁盘与电池，磁盘含读写速度与累计量，
    网络含速度曲线、出口接口、内网与公网 IP。
    点击卡片标题行右侧的时长胶囊下拉选择这张卡的曲线跨度，可选近 1 分钟、5 分钟与 15 分钟，
    默认近 1 分钟，四张卡各自记住自己的选择，互不影响；
    温度曲线在最高核心温度与平均值差距明显时叠加一条峰值细线。
    5 分钟与 15 分钟档按固定时间格聚合采样，最右一格随最新采样实时更新，
    填满后曲线整体左移一格，已经画出的部分不再改变。
    曲线按当前跨度内的最小值到最大值纵向填满，空闲时的细微起伏也能看出来；
    曲线右侧一列小字标出这段时间的最大值与最小值，随每秒新数据和跨度切换更新。
  - AI：ChatGPT 与 Claude 的 5 小时、7 天、专属模型与企业月度额度，以及 OpenCode Go 的滚动、每周、
    每月用量；显示订阅徽章与重置时间，Claude Max 可显示 5× / 20× 等级。
    Codex 周进度条使用服务端每日明细分段；单卡刷新时显示动画并阻止重复请求，
    超过 60 秒仍未返回会中止本次刷新并标记为失败，卡片不会一直转圈。
  - 设置：拖拽分屏开关、布局配置、辅助功能权限、AI 用量自动刷新间隔与数据过期阈值、
    开机自启、重启与退出。
- 分屏布局配置保存后自动热重载，无需手动重新加载；
  配置目录被删除或被同步工具整体替换后会自动重新监视，不需要重启应用。
  坐标为负、宽高为零或越出屏幕的分区会被忽略，某块屏幕一个可用分区都不剩时回落到默认布局。
- 按住 Shift 拖动窗口，可将窗口吸附到当前显示器的指定分区。
- 按住 Shift 双击窗口标题栏，对同一窗口依次循环居中、填充与还原，
  语义对应系统「窗口」菜单的居中与填充；换窗口或手动移动过窗口后从居中重新开始。
- 按住 Shift 约 1 秒且不进行其他操作，进入分割线编辑模式：
  拖动分割线即可调整相邻分区的比例，松开 Shift 保存，按 Esc 放弃修改。
  保存会重写 `~/.config/myowntool/layouts.json`，手写的排版格式会被规范化。
- 设置里的拖拽分屏开关会被记住，关闭后上面三个 Shift 手势一并停用。
- 支持为内置、外接和指定显示器设置不同的窗口布局。

系统温度、GPU 与磁盘数据取决于具体 Mac 机型，无法读取时会显示为空。
AI 用量会读取本机已登录的 Codex 或 Claude Code 凭证，不需要在应用中再次登录。
应用只读凭证，不刷新或写回 token；Claude 返回 401 时会提示运行 `claude auth login`。
Codex 会沿用 `config.toml` 中经过严格 HTTPS 校验的 `chatgpt_base_url`，并把企业 individual limit 显示为月度额度；
断网降级到本地会话快照时，ChatGPT 订阅徽章仍会按本机登录信息显示。
OpenCode Go 优先只读本地 SQLite 历史，并按公开额度显示带「本地估算」标识的滚动、每周与每月用量；
本地数据不可用时，再从 Chrome、Arc、Brave、Edge、Vivaldi 或 Chromium 导入 `opencode.ai` 登录 cookie，
读取网页工作区的实时用量；cookie、工作区 ID 和原始响应只在内存中使用，不会保存或记录。
后台与睡眠唤醒刷新不会弹出钥匙串授权界面；用户点击 Claude 或 OpenCode 卡片刷新，或显式运行
AI 探针时，macOS 才可能请求访问 Claude Code 凭证或对应浏览器的 Safe Storage 钥匙串项目。
拒绝后相应卡片会显示凭证不可用，已有快照仍会保留。

AI 提供方、降级策略、安全边界和扩展步骤见 [AI 用量接入架构](docs/AI_USAGE.md)。
