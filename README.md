# MyOwnTools

MyOwnTools 是一个个人 macOS 菜单栏工具，用来查看系统状态和 AI 订阅用量，也可以快速整理窗口。
当前版本为 `0.1.0`。

## 功能

- 菜单栏从左到右显示：上传下载速度、CPU/GPU/RAM 占用竖柱、ChatGPT 与 Claude 用量双层环。
  竖柱边框颜色表示温度分级，CPU/GPU 取自身温度，RAM 柱取硬盘温度，90℃ 以上闪烁警示。
  用量环外环为 5 小时窗口、内环为 7 天窗口，5 小时限额暂时取消时外环显示为虚点。
- 点击菜单栏状态区打开弹窗，分三个选项卡：
  - 系统：占用率含 E/P 核占用与平均负载，温度含磁盘与电池，磁盘含读写速度与累计量，
    网络含速度曲线、出口接口、内网与公网 IP。
  - AI：ChatGPT 与 Claude 的 5 小时、7 天和专属模型用量、订阅徽章与重置时间，可单卡刷新。
  - 设置：拖拽分屏开关、布局配置、辅助功能权限、AI 用量自动刷新间隔、开机自启、重启与退出。
- 分屏布局配置保存后自动热重载，无需手动重新加载。
- 按住 Shift 拖动窗口，可将窗口吸附到当前显示器的指定分区。
- 支持为内置、外接和指定显示器设置不同的窗口布局。

系统温度、GPU 与磁盘数据取决于具体 Mac 机型，无法读取时会显示为空。
AI 用量会读取本机已登录的 Codex 或 Claude Code 凭证，不需要在应用中再次登录。
