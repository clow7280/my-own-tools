# MyOwnTool

MyOwnTool 是一个个人 macOS 菜单栏工具，用来查看系统状态和 AI 订阅用量，也可以快速整理窗口。

## 功能

- 菜单栏实时显示上传、下载速度，以及 CPU、GPU、内存占用。
- 点击菜单栏状态区可查看占用曲线、温度、网络地址和应用设置。
- 展示 Codex 与 Claude 的 5 小时和 7 天用量，Gemini 暂未接入。
- 按住 Shift 拖动窗口，可将窗口吸附到当前显示器的指定分区。
- 支持为内置、外接和指定显示器设置不同的窗口布局。

系统温度和 GPU 数据取决于具体 Mac 机型，无法读取时会显示为空。
AI 用量会读取本机已登录的 Codex 或 Claude Code 凭证，不需要在应用中再次登录。
