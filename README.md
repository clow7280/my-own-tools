# MyOwnTools

MyOwnTools 是一个个人 macOS 菜单栏工具，用来查看系统状态和快速整理窗口。
需要 macOS 15 及以上，当前版本为 `0.4.0`。

## 功能

- 菜单栏从左到右显示上传下载速度与 CPU/GPU/RAM 占用竖柱。
  竖柱边框颜色表示温度分级，CPU/GPU 取自身温度，RAM 柱取硬盘温度，90℃ 以上闪烁警示。
- 点击菜单栏状态区打开「系统 / 设置」弹窗。
  - 系统页显示 CPU、GPU、RAM、温度、磁盘和网络状态，包括 E/P 核占用、平均负载、
    磁盘累计读写、出口接口、内网 IP 与公网 IP。
  - 点击卡片标题行右侧的时长胶囊，可为每张卡分别选择近 1 分钟、5 分钟或 15 分钟曲线。
    曲线按固定时间格聚合采样，右侧显示当前跨度的最大值与最小值。
  - 设置页提供拖拽分屏开关、布局配置、辅助功能权限、开机自启、重启与退出。
- 按住 Shift 拖动窗口时显示当前屏幕的配置分区，并在顶部显示「全屏」与「专注」目标。
  - 拖到普通分区后松开，窗口吸附到该分区。
  - 拖到「全屏」后松开，窗口填满当前屏幕的可用区域，不进入 macOS 原生全屏空间。
  - 拖到「专注」后松开，窗口保留原尺寸并移动到可用区域中央；
    原尺寸超出可用区域时会先夹取尺寸。
    从本工具的全屏布局直接切换到专注时，会恢复进入全屏前的窗口尺寸。
- 按住 Shift 约 1 秒且不进行其他操作，进入分割线编辑模式。
  - 拖动分割线调整相邻分区比例。
  - 右键分区，选择「左右分割」或「上下分割」以增加分割线。
  - 右键分割线删除指针所在的线段。
  - 松开 Shift 保存，按 Esc 放弃修改。
- 分屏布局配置保存后自动热重载，无需手动重新加载。
  配置目录被删除或被同步工具整体替换后会自动重新监视，不需要重启应用。
  坐标为负、宽高为零或越出屏幕的分区会被忽略，某块屏幕一个可用分区都不剩时回落到默认布局。
- 支持为内置、外接和指定显示器设置不同的窗口布局。
  设置里的拖拽分屏开关会被记住，关闭后所有 Shift 窗口手势一并停用。

分割线编辑保存时会重写 `~/.config/myowntool/layouts.json`，手写的排版格式会被规范化。
系统温度、GPU 与磁盘数据取决于具体 Mac 机型，无法读取时会降级显示为空。

## 构建与验证

```sh
swift build
swift run StatsCoreChecks
swift run MyOwnTools
swift run MyOwnTools --stats-probe
./scripts/make-app.sh
```

辅助功能、菜单栏、失焦交互和多显示器布局需要在图形会话中手工验证。
